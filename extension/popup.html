    Расширению нужен локальный помощник, через который оно меняет список маршрутизации Throne. Установите его один раз:

    1. Скачайте архив ThroneSiteAdder-host со страницы Releases на GitHub и распакуйте.
    2. Запустите в ней install.cmd (двойной клик) или выполните в PowerShell:
      powershell -ExecutionPolicy Bypass -File install.ps1 -ExtensionId
    3. Перезапустите браузер.
