# Изменения host

Релизы host помечаются тегами `host-v<версия>`. Изменения расширения ведутся в [CHANGELOG-extension.md](CHANGELOG-extension.md).

## 1.0.2

* В README добавлена инструкция по установке расширения без Chrome Web Store.
* Сам host не изменился.

## 1.0.1

* Исходники и тесты host выложены в репозиторий.
* Релиз собирается и публикуется автоматически через GitHub Actions.
* В README добавлена ссылка на страницу Releases.

## 1.0.0

Первый релиз.

* Добавление и удаление доменов, wildcard `*.example.com`, IP-адресов и подсетей, а также импорт списка в правило proxy активного профиля маршрутизации Throne.
* Перезапуск профиля через Throne API: клиент `throne-api/1` на чистом Python. Ключ, порт и флаг включения API берутся из конфига Throne.
* Запись одной SQLite-транзакцией и бэкап `throne.db` перед каждым изменением.
* `install.cmd` / `uninstall.cmd` для Chrome, Yandex Browser, Chromium, Edge и Firefox, права администратора не нужны.
